# Contributing

Thanks for your interest in the Product Owner Toolkit.

- **Issues first.** For anything beyond a small fix, open an issue to discuss the change before sending a pull request.
- **Pull requests** target `main` and are squash-merged. Keep each PR focused on one change.
- **No secrets.** Don't commit API keys, tokens, or real company data. Use `{Company XYZ}`-style placeholders in context and examples.
- **Security issues** go through [`SECURITY.md`](SECURITY.md), not public issues.
