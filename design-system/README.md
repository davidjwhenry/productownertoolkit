# Design System

This folder stores reusable brand and UI reference material that drafting and reporting workflows can reuse.

## Put Here

- Brand tokens
- Voice and tone guidance
- UI patterns or component references
- Pencil files or other design artefacts used as examples

## Rules

- Keep source-of-truth design references here, not inside `examples/` (if it still exists).
- Prefer reusable system guidance over one-off screen mocks.
- If a file is only illustrative, label it clearly as an example.
- Keep this folder focused on assets and guidance that can support multiple artefacts.
