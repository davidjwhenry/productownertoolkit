# Meeting Note Format

## Template

```markdown
# [Meeting Title]

**Date:** YYYY-MM-DD  
**Participants:** Name (Role), Name (Role)

## Context

[1-2 sentences on why this meeting happened and what was being addressed]

## Key Decisions

1. [Decision]
2. [Decision]

## Action Items

- [ ] **[Owner]** — [Task] _(by [date if known])_

## Open Questions

- [Unresolved question]

## Notes

[Important context, discussions, or background not captured above]
```

## Guidelines

- Skip any section that has nothing meaningful to add — don't leave empty headings
- Action items should always have an owner; use `@name` or full name
- If an owner or due date is unclear, keep the action item only if the task itself is clear and mark the missing detail as unknown
- Decisions should be stated as facts, not as discussion points ("Decided to X", not "Discussed X")
- Do not promote tentative ideas into decisions unless the source clearly shows agreement
- Notes section is for colour and context, not a full transcript
- Keep confidential or sensitive personal observations out of reusable team context files
