# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's [private vulnerability reporting](https://github.com/davidjwhenry/productownertoolkit/security/advisories/new). Include what you found, where it is, and how to reproduce it. You'll get a response as soon as possible.

## Credentials

This toolkit connects to services such as Notion, Figma, GitHub, and Firecrawl through MCP. Never commit API keys or tokens to this repo, including in forks. Keep them in your local MCP client configuration or environment variables.
