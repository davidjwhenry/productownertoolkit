# User Preferences

This file stores learned preferences from working sessions. Skills read it before drafting, reviewing, or presenting output, and may propose additions after a session when a durable preference is observed.

## How This File Works

- Skills read this file during their setup or research phase alongside `company-context.md` and `team-context.md`.
- When a skill observes a clear, reusable preference during a session, it proposes an addition here. The user must confirm before anything is written.
- Preferences are grouped by category. Add new entries under the most relevant heading, or create a new heading if none fits.
- If a preference conflicts with an earlier entry, replace the old one rather than adding a contradictory line.
- Keep entries concise: one bullet per preference, with enough context to be actionable.
