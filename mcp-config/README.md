# MCP Setup Guide

Use this folder to decide which MCPs to connect when you first set up the toolkit.

Unless noted otherwise, the code samples in this folder are `mcp.json` extracts for Cursor. Merge the relevant server block into your existing `.cursor/mcp.json` or `~/.cursor/mcp.json` file rather than pasting multiple full examples on top of each other.

## Recommended first

- `Firecrawl` for external research and web extraction
- `pen.dev` for rapid prototypes and UI exploration

## Add if relevant

- `Notion` if your team stores PRDs, tickets, notes, or decisions there
- `Figma` if you want design context available while writing PRDs or reviewing flows
- `GitHub` if you want repo-aware shipping context inside the same workspace

## Current scope

Meeting and voice-capture MCP setup is intentionally not included yet. Add those later when the related workflows land in the repo.
